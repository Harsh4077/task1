# Semantic HTML Personal Profile Page
Project Overview

This project is a fully semantic and accessible personal profile web page built using HTML5 semantic elements.
The objective is to demonstrate proper page structure, accessibility best practices, and clean, readable code without relying on generic <div> tags.

The page presents personal information such as name, bio, education, skills, and contact details, while ensuring logical content separation and improved usability for assistive technologies.

Objectives

Use semantic HTML elements to structure web content

Improve accessibility and readability

Implement internal page navigation

Follow HTML5 best practices

Avoid non-semantic markup like excessive <div> usage

Technologies Used

HTML5

No external libraries or frameworks

Browser-independent and standards-compliant

File Structure
/project-folder
│
├── index.html        # Main semantic HTML profile page
├── profile.jpg       # Profile image (user-provided)
└── README.md         # Project documentation

Semantic Elements Used
Element	Purpose
<header>	Contains the page title and navigation
<nav>	Holds internal navigation links
<main>	Wraps the primary page content
<section>	Groups related content sections
<article>	Self-contained content blocks
<footer>	Displays copyright information
<address>	Holds contact information

These elements improve:

Screen reader support

Search engine understanding

Code maintainability

Accessibility Features

Proper heading hierarchy (<h1> → <h3>)

Descriptive alt text for images

Semantic navigation using <nav>

Contact details wrapped in <address>

Keyboard-friendly internal links

Internal Navigation

The navigation bar uses anchor links to jump to sections within the page:

About Me

Education

Skills

Contact Information

This enhances usability and user experience.

How to Run the Project

Download or clone the project folder

Ensure index.html and profile.jpg are in the same directory

Open index.html in any modern browser:

Google Chrome

Mozilla Firefox

Microsoft Edge

No server or installation is required.
